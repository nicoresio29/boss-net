Bienvenido a boss.net

Para usar el agente necesitás tu propia API key de Groq. Es gratis, no pide tarjeta y tarda unos 2 minutos.

  1. 1
    Creá tu cuenta en Groq

    Entrá a console.groq.com y registrate con tu mail o con Google.

    Abrir console.groq.com →
  2. 2
    Entrá a la sección de API Keys

    En el menú de la izquierda elegí API Keys, o entrá directo.

    Ir a API Keys →
  3. 3
    Creá una clave nueva

    Tocá Create API Key, ponele un nombre (por ejemplo, boss) y confirmá.

  4. 4
    Copiá la clave

    Empieza con gsk_. Groq la muestra una sola vez, así que copiala en ese momento.

  5. 5
    Pegala abajo

    Sin espacios al principio ni al final.

Tu clave se guarda solo en este navegador y se envía únicamente a Groq. No la uses en computadoras que no sean tuyas.
